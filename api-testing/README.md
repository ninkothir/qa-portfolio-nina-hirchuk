# API Testing Project

## Project Description

This project demonstrates API testing skills using Postman and the JSONPlaceholder REST API.

## Tools

- Postman
- JSONPlaceholder
- REST API

## Tested Requests

- GET All Posts
- GET Post by ID
- POST Create Post
- PUT Update Post
- DELETE Post

## Automated Tests

Each request contains automated tests that verify the HTTP status code using Postman Scripts.
