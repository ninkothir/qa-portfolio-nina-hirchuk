# Hotel Booking Platform - QA Project

## Project Description

This project demonstrates manual testing of a hotel booking web application.

The main user flows covered in this project include:

- hotel search
- destination input
- autocomplete suggestions
- check-in date selection
- check-out date selection

## Testing Type

- Manual Testing
- Functional Testing
- Positive Testing
- Negative Testing
