# Hotel Booking Platform – QA Project

## Project Description

This project demonstrates manual testing of a hotel booking web application.

The testing covers the main user flows, including:

- Hotel search
- Date selection
- Filters
- Sorting
- Hotel details
- Booking process
- API Testing
- SQL Validation
