# BR-003 - Sample Bug Report: Search without destination

## Summary
The application allows starting a search without entering a destination.

## Environment
- Application: Booking.com
- Browser: Google Chrome
- OS: Windows 11

## Preconditions
- Open booking.com.

## Steps to Reproduce
1. Open booking.com.
2. Leave the destination field empty.
3. Select valid dates.
4. Click the "Search" button.

## Expected Result
The application should display a validation message asking the user to enter a destination.

## Actual Result
The search starts without requesting a destination.

## Severity
Medium

## Priority
Medium

## Status
Open
