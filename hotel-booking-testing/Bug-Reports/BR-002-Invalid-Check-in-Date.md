# BR-002 - Sample Bug Report: Invalid check-in date is accepted

## Summary
The application allows selecting a check-in date that is earlier than the current date.

## Environment
- Application: Booking.com
- Browser: Google Chrome
- OS: Windows 11

## Preconditions
- Open booking.com.

## Steps to Reproduce
1. Open booking.com.
2. Try to select a check-in date in the past.
3. Confirm the selected date.

## Expected Result
The application should not allow selecting a past check-in date.

## Actual Result
A past check-in date is accepted.

## Severity
High

## Priority
High

## Status
Open
