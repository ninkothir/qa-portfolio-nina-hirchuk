# BR-001 – Search button does not start search

## Summary
The search does not start after clicking the **Search** button with valid data entered.

## Environment
- Application: Booking.com
- Browser: Google Chrome
- OS: Windows 11

## Preconditions
- Open Booking.com.
- Enter a valid destination.
- Select valid check-in and check-out dates.
- Select 2 adults.

## Steps to Reproduce
1. Open Booking.com.
2. Enter "Berlin".
3. Select valid dates.
4. Click **Search**.

## Expected Result
The search results page is opened.

## Actual Result
Nothing happens after clicking the Search button.

## Severity
Medium

## Priority
High

## Status
Open
