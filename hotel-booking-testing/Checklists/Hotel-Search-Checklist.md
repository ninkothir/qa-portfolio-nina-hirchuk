# Hotel Search Checklist

## Project Information

**Application:** Booking.com  
**Platform:** Web  
**Testing Type:** Manual Functional Testing  
**Module:** Hotel Search  
**Environment:** Google Chrome on Windows  

## Preconditions

- Booking.com is available.
- The user is not signed in.
- The browser has an active internet connection.
